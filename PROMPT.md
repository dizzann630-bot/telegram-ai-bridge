ШАГ 1. Ключи Telegram — я делаю сам, без тебя.
В России my.telegram.org с VPN выдаёт ERROR, поэтому VPN придётся выключить, а без VPN
ты перестанешь отвечать. Поэтому этот шаг ты не выполняешь, а сразу присылаешь мне
инструкцию ниже — красиво оформленной: заголовок, нумерованные шаги, кнопки, файлы и
поля жирным, ссылки кликабельными. Смысл, порядок и ссылки не меняй, ничего не добавляй.
Потом ждёшь «готово».

## Шаг 1 — ключи Telegram (≈5 минут, делаете сами)
Когда выключите VPN, я перестану отвечать — это нормально. Вернётесь сюда в конце.
Если вы не в России — пропустите пункты 1, 2, 3 и 7.

**Пока VPN включён**
1. Откройте https://github.com/Flowseal/zapret-discord-youtube/releases/latest (только эту ссылку). Прокрутите вниз до **Assets** и скачайте **третий файл — `zapret-discord-youtube-…zip`**. В «Загрузках»: правой кнопкой по архиву → **«Извлечь всё»** → путь **`C:\zapret`**. Если Chrome пишет «Подозрительное скачивание заблокировано» — откройте загрузки (стрелка вверху справа) и выберите скачать файл всё равно. Антивирус ругается на WinDivert — разрешите.

**Дальше**
2. **Выключите VPN.**
3. В папке **`C:\zapret`** дважды кликните **`general.bat`**. Если Windows спросит разрешение — **«Да»**. Чёрное окно не закрывайте. Если вместо этого пишет «zapret is ALREADY RUNNING as service» — всё хорошо, он уже работает: нажмите любую клавишу и идите дальше.
4. Откройте https://my.telegram.org → номер **полностью, с +7** → **Next** → код придёт **в приложение Telegram** (не SMS) → введите → **Sign In**.
5. **API development tools** → заполните: **App title** `AI Bridge`, **Short name** `aibridge` + любые 5 цифр, **Platform** `Desktop`, остальное пусто → **Create application**. Если там уже есть ключи — ничего не заполняйте.
6. Вкладку с **api_id** и **api_hash** **не закрывайте** — они понадобятся позже. api_hash никому не отправляйте. В **Delete account** ничего не нажимайте.
7. Закройте чёрное окно zapret и **включите VPN**.
8. Напишите сюда **«готово»**.

**Если код не пришёл за 2 минуты или ERROR:** закройте чёрное окно → откройте Блокнотом **`C:\zapret\lists\list-general-user.txt`** → допишите строку `telegram.org` → сохраните → запустите **`general (ALT).bat`** → «Да» → повторите с пункта 4. Не помогло — **`general (ALT2).bat`**, потом **(ALT3)** и т. д.

ШАГ 3. Render.
Открой https://dashboard.render.com, я вхожу через GitHub. Затем New → Blueprint →
подключи GitHub, выбери мой форк telegram-ai-bridge, Blueprint Name: telegram-ai.
В переменных:
  ADMIN_PASSWORD — я придумываю и ввожу сам (от 10 символов, его надо запомнить);
  TELEGRAM_API_ID и TELEGRAM_API_HASH — я копирую с открытой вкладки my.telegram.org и вставляю сам;
  TELEGRAM_SESSION — впиши один знак минус: -
Перед деплоем проверь, что у сервиса тариф Free (Instance Type: Free) — если видишь
платный тариф или просьбу ввести карту, остановись и скажи мне.
ВАЖНО: все 4 значения вводятся прямо на этой странице, до кнопки Deploy.
Если сервис всё же создался без них — Render → сервис → Environment → Edit →
Add variable и добавь те же 4 переменные, затем «Save, rebuild, and deploy».
→ «Deploy Blueprint». Дождись статуса Live (3–5 минут) и запомни адрес сервиса
вида https://telegram-ai-xxxx.onrender.com (дальше — АДРЕС).

ШАГ 4. Проверка.
Открой АДРЕС/health. Должно быть "telegram_keys_set":true и "password_set":true.
Если false — проверь переменные в Render → Environment.

ШАГ 5. Вход в Telegram.
Открой АДРЕС/setup. Я ввожу ADMIN_PASSWORD, потом вхожу по номеру телефона или по QR
(я сам). Дальше я следую инструкции на странице: копирую строку, открываю Render,
Edit → 5-я строка TELEGRAM_SESSION → вставляю → «Save, rebuild, and deploy».
Ты только подсказываешь, строку не трогаешь. Через 2–3 минуты открой АДРЕС/health:
должно быть "telegram_configured":true.

ШАГ 6. Подключение к ChatGPT (на компьютере, в браузере).
chatgpt.com → Плагины → «Добавить» → пункт для своего MCP-сервера / по URL.
Название: Telegram. URL: АДРЕС/mcp. Аутентификация: OAuth (Client ID и Secret пустые).
Если есть галочка «доверяю» — поставь → «Создать». На странице входа я ввожу
ADMIN_PASSWORD и нажимаю «Разрешить».
Если после входа ChatGPT пишет «action discovery failed» или плагин без инструментов —
сервер просто просыпался: удали этот плагин и добавь его заново тем же способом.
(Для Claude: Настройки → Коннекторы → Добавить свой коннектор → АДРЕС/mcp.)

ШАГ 7. Тест.
Новый чат → «+» → Telegram → напиши: «Кто я в Telegram? Покажи 10 последних чатов».
Если пришёл ответ — готово, скажи мне об этом.
