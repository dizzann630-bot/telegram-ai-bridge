# Промпт для ChatGPT: пошаговая инструкция

Скопируй текст ниже целиком и вставь в ChatGPT (режим «Работа»). Он будет вести тебя
по шагам: что открыть, куда нажать, что вписать. Всё делаешь ты сам руками, в своём
браузере. Пароли, коды и ключи ты вводишь только на сайтах и никогда не отправляешь в чат.

```
Помоги мне подключить мой Telegram к ChatGPT через MCP-сервер
https://github.com/dizzann630-bot/telegram-ai-bridge (бесплатный хостинг Render).
Я всё делаю сам в своём браузере, а ты — мой гид.

КАК ВЕСТИ МЕНЯ:
- Давай по одному шагу за раз: коротко, нумерованно, кнопки и поля **жирным**,
  ссылки кликабельными. После шага жди, пока я напишу «готово» или задам вопрос.
- Если я прислал скриншот — смотри на него и говори, куда нажать дальше.
- Если что-то пошло не так — спроси, что я вижу на экране, и предложи решение.

ПРАВИЛА БЕЗОПАСНОСТИ (строго):
- Никогда не проси прислать в чат: номер телефона, коды из Telegram, любые пароли
  (Telegram, GitHub, Render, ADMIN_PASSWORD), api_hash, строку сессии.
  Если я случайно пришлю что-то из этого — предупреди и скажи, что это надо сменить.
- Подсказывай, в какое поле на сайте это вписать, а вписываю я сам.
- На my.telegram.org ничего не нажимать в разделе «Delete account».
- На странице /setup строку сессии не показывать и никуда не пересылать —
  только кнопка «Скопировать строку» и сразу вставить в Render.
- Не используй подключённые плагины/коннекторы (Render, GitHub и др.), даже если они
  есть: всё делаем через сайты по шагам ниже. Иначе секреты пойдут через чат.

ШАГ 1. Ключи Telegram.
В России my.telegram.org с VPN выдаёт ERROR, поэтому VPN придётся выключить, а без VPN
ты перестанешь отвечать. Поэтому сразу пришли мне весь этот шаг целиком — красиво
оформленным: заголовок, нумерованные пункты, кнопки, файлы и поля жирным, ссылки
кликабельными. Смысл, порядок и ссылки не меняй, ничего не добавляй. Потом жди «готово».

## Шаг 1 — ключи Telegram (≈5 минут)
Когда выключите VPN, я перестану отвечать — это нормально. Вернётесь сюда в конце.
Если вы не в России — пропустите пункты 1, 2, 3 и 7. Если ключи уже есть — сразу пишите «готово».

**Пока VPN включён**
1. Откройте https://github.com/Flowseal/zapret-discord-youtube/releases/latest (только эту ссылку). Прокрутите вниз до **Assets** и скачайте **третий файл — `zapret-discord-youtube-…zip`**. Если Chrome пишет «Подозрительное скачивание заблокировано» — откройте загрузки (стрелка вверху справа) и выберите скачать файл всё равно. Антивирус ругается на WinDivert — разрешите. Распакуйте архив на диск C: правой кнопкой → **«Извлечь всё»** → путь **`C:\zapret`**.

**Дальше**
2. **Выключите VPN.**
3. В папке **`C:\zapret`** в самом низу дважды кликните **`general.bat`**. Если Windows спросит разрешение — **«Да»**. Чёрное окно не закрывайте. Если вместо этого пишет «zapret is ALREADY RUNNING as service» — всё хорошо, он уже работает: нажмите любую клавишу и идите дальше.
4. Откройте https://my.telegram.org → номер **полностью, с +7** → **Next** → код придёт **в приложение Telegram** (не SMS) → введите → **Sign In**.
5. **API development tools** → заполните: **App title** `AI Bridge`, **Short name** `aibridge` + любые 5 цифр, **Platform** `Desktop`, остальное пусто → **Create application**. Если там уже есть ключи — ничего не заполняйте.
6. Вкладку с **api_id** и **api_hash** **не закрывайте** — они понадобятся позже. api_hash никому не отправляйте. В **Delete account** ничего не нажимайте.
7. Закройте чёрное окно zapret и **включите VPN**.
8. Напишите сюда **«готово»**.

**Если код не пришёл за 2 минуты или ERROR:** закройте чёрное окно → откройте Блокнотом **`C:\zapret\lists\list-general-user.txt`** → допишите строку `telegram.org` → сохраните → запустите **`general (ALT).bat`** → «Да» → повторите с пункта 4. Не помогло — **`general (ALT2).bat`**, потом **(ALT3)** и т. д.

ШАГ 2. GitHub — своя копия проекта.
Скажи мне открыть https://github.com/dizzann630-bot/telegram-ai-bridge (войти или
зарегистрироваться, если нужно) → **Fork** → **Create fork**.

ШАГ 3. Render — бесплатный сервер.
Скажи: открыть https://dashboard.render.com → войти через GitHub → **New** → **Blueprint** →
подключить GitHub → выбрать свою копию telegram-ai-bridge → Blueprint Name: `telegram-ai`.
На этой же странице, до кнопки Deploy, вписать 4 значения:
  ADMIN_PASSWORD — придумать самому (от 10 символов) и запомнить, в чат не писать;
  TELEGRAM_API_ID и TELEGRAM_API_HASH — скопировать с открытой вкладки my.telegram.org;
  TELEGRAM_SESSION — один знак минус: -
Проверить, что тариф **Free**. Если Render просит карту или показывает платный тариф —
остановиться и сказать тебе.
Если сервис создался без переменных — Render → сервис → **Environment** → **Edit** →
**Add variable**, добавить те же 4 и нажать **Save, rebuild, and deploy**.
Затем **Deploy Blueprint** → ждать статус **Live** (3–5 минут) и скопировать адрес
сервиса вида https://telegram-ai-xxxx.onrender.com (дальше — АДРЕС).

ШАГ 4. Проверка сервера.
Открыть АДРЕС/health. Должно быть "telegram_keys_set":true и "password_set":true.
Если false — проверить переменные в Render → Environment.

ШАГ 5. Вход в Telegram.
Открыть АДРЕС/setup → ввести ADMIN_PASSWORD → войти по номеру телефона или по QR.
Дальше по инструкции на странице: **Скопировать строку** → открыть Render →
**Environment** → **Edit** → 5-я строка TELEGRAM_SESSION → заменить минус на строку →
**Save, rebuild, and deploy**. Через 2–3 минуты открыть АДРЕС/health:
должно быть "telegram_configured":true.

ШАГ 6. Подключение к ChatGPT (на компьютере, в браузере).
chatgpt.com → **Плагины** → **Добавить** → свой MCP-сервер.
Название: Telegram. URL: АДРЕС/mcp. Аутентификация: **OAuth** (Client ID и Secret пустые).
Если есть галочка «доверяю» — поставить → **Создать**. На странице входа ввести
ADMIN_PASSWORD → **Разрешить**.
Если ChatGPT пишет «action discovery failed» или плагин без инструментов — сервер
просто просыпался: удалить плагин и добавить заново тем же способом.
(Для Claude: Настройки → Коннекторы → Добавить свой коннектор → АДРЕС/mcp.)

ШАГ 7. Тест.
Новый чат → **«+»** → Telegram → написать: «Кто я в Telegram? Покажи 10 последних чатов».
Пришёл ответ — всё готово.
```

После настройки можно закрыть вкладки. Строку сессии нигде не храни, кроме Render.
