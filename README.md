# Telegram для твоего ИИ (ChatGPT и Claude)

MCP-сервер, через который ChatGPT, Claude и Claude Code работают с твоим Telegram:
читают чаты и каналы, ищут сообщения, выгружают переписку, отправляют сообщения
(только после твоего «да»), ставят отложенные посты с фото и альбомами.

Работает бесплатно на Render. Доступ защищён твоим паролем (встроенный OAuth).

## Что умеет

| Инструмент | Что делает |
| --- | --- |
| `list_chats` | список чатов, групп, каналов (id для остальных инструментов) |
| `read_chat`, `export_chat` | последние сообщения / вся переписка частями |
| `search_messages` | поиск по одному чату или по всем |
| `channel_info`, `similar_channels` | описание канала и похожие каналы |
| `preview_message` → `send_message` | отправка: сначала предпросмотр, потом подтверждение |
| `schedule_post`, `list_scheduled` | отложенные посты в свои каналы и «Избранное» |
| `attach_chatgpt_files`, `get_upload_link`, `upload_from_url` | фото, видео, файлы для отправки |

## Установка

Проще всего: скопируй [PROMPT.md](PROMPT.md) в ChatGPT (режим «Работа») — он проведёт по шагам, а ты делаешь всё руками.

1. Ключи Telegram: <https://my.telegram.org> → API development tools → создать приложение →
   скопировать `api_id` и `api_hash`.
   Из России: сайт работает только без VPN и с обходом блокировки (zapret), иначе форма даёт `ERROR`.
2. Форкни этот репозиторий и создай на <https://render.com> Blueprint из своего форка.
   Render спросит переменные:
   - `ADMIN_PASSWORD` — придумай пароль от 10 символов (им ты будешь подключать ИИ);
   - `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` — из шага 1;
   - `TELEGRAM_SESSION` — впиши `-`;
   - `SECRET_KEY` Render создаст сам.
3. Открой `https://<твой-сервис>.onrender.com/setup`, введи пароль, войди по номеру телефона
   или по QR. Скопируй строку и вставь в Render → Environment → Edit → `TELEGRAM_SESSION`
   (5-я строка) → Save, rebuild, and deploy.
4. Подключи к ИИ адрес `https://<твой-сервис>.onrender.com/mcp`:
   - **ChatGPT** (в браузере на компьютере): Плагины → «Добавить» → свой MCP-сервер → адрес → OAuth → вход паролем.
   - **Claude**: Настройки → Коннекторы → добавить свой коннектор → адрес → вход паролем.
   - **Claude Code**: `claude mcp add --transport http telegram https://<твой-сервис>.onrender.com/mcp`, затем `/mcp` → вход.

## Безопасность

- `TELEGRAM_SESSION` = полный доступ к аккаунту. Храни только в секретах Render, никому не отправляй.
- Отправка сообщений — только после предпросмотра и твоего согласия. Отложенные посты — только в свои каналы.
- Выкинуть все подключённые ИИ: смени `SECRET_KEY` в Render.
- Отключить Telegram: Telegram → Настройки → Устройства → завершить сеанс.

Бесплатный Render засыпает после 15 минут простоя: первый запрос после сна идёт ~30–60 секунд.
